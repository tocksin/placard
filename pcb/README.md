# PCB layout

This folder holds the Placard PCB layout: the board files, plus fabrication
outputs (Gerbers, drill files, BOM, pick-and-place) under `fab/` when a board
is ordered.

The schematic lives in [`../schematics/`](../schematics/).  The board size
estimate is: main board about 11.4" x 5.5" (4-layer) at keyboard width, with
the ROM on a plug-in cartridge (2x20 card-edge slot) and four card-edge
expansion slots.
